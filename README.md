# Секретный чат

## Доступ к чату

Это веб-приложение (чат) node.js - Часть проекта "**Секретный Чат**". В него входит как это веб-приложение, так и
OpenVPN сервер / безопасность сервера (Настройка брандмауэра iptables и т.д.), как этого веб-сервера так и openVPN сервера. В локальной сети веб-сервера
есть два компьютера, один служит как VPN сервер, другой - сам чат. Удаленный клиент получает доступ к чату только через OpenVPN 
(Исключением является ситуация, когда клиент находится в одной локальной сети с сервером VPN). VPN-туннель шифрует данные передаваемые клиентом.<br/>

# Функции этого приложения

Секретный чат не хранит сообщения на сервере, или любом другом хранилище, при переписке с человеком они отображаются на клиенской стороне, 
но при обновлении страницы сообщения исчезают. Чтобы попасть в чат, нужно зайти в свой аккаунт, для переписки с человеком нужно подключиться к нему по его никнейму (username - уникален). Приложение всегда уведомит человека об ошибке при отправке, или если собеседник не в онлайн, (Или при любых других условиях).
