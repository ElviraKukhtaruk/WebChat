# Секретный чат

Это веб-приложение (чат) node.js - Часть проекта "**Секретный Чат**". В него входит как это веб-приложение, так и настройка
OpenVPN сервера и безопасность сервера (Настройка брандмауэра iptables и т.д.), как этого веб-сервера так и openVPN сервера. В локальной сети веб-сервера
есть два компьютера, один служит как VPN сервер, другой - сам чат. Удаленный клиент получает доступ к чату только через OpenVPN 
(Исключением является ситуация, когда клиент находится в одной локальной сети с сервером VPN). VPN-туннель шифрует данные передаваемые клиентом.<br/>

# Функции этого приложения

Секретный чат не хранит сообщения на сервере, или любом другом хранилище, при переписке с человеком они отображаются на клиенской стороне, 
но при обновлении страницы сообщения исчезают. В чате могут одновременно присутствовать только 2 человека, (Чат был написан специально для 2-х человек) 
для дополнительной безопасности. Так же, чтобы написать человеку сообщение, секретное слово собеседника должно совпадать с вашим, 
иначе собеседник просто не увидит вашего сообщения. Приложение всегда уведомит человека об ошибке при отправке, 
или если ваше секретное слово не совпадает с секретным словом другого пользователя (Или при любых других условиях).
